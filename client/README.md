# Nature360 / EcoTrack client

React 19 + Vite + Tailwind CSS app. See the [project README](../README.md) for
setup, environment variables, and run commands.

```bash
npm install
cp .env.example .env   # fill in Firebase config + VITE_API_URL
npm run dev
```

The app expects the API at `VITE_API_URL` (default `http://localhost:5000/api`).
